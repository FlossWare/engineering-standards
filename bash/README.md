# Bash/Shell Quality Tools Templates

Standardized Bash testing and quality tool configurations.

## Templates Included

### Linting & Formatting
- `.shellcheckrc` - ShellCheck configuration
- `.shfmt.yaml` - shfmt formatter settings
- `.editorconfig` - Editor consistency

### Testing Framework
- `tests/setup.bash` - Bats test helpers and utilities
- `tests/test_helpers.bash` - Custom assertion functions
- `tests/test_example.bats` - Example test suite
- `tests/install-bats-helpers.sh` - Install bats libraries

### Build & CI
- `Makefile` - Complete build automation
  - Lint (shellcheck), format (shfmt), test (bats)
  - Coverage (kcov 70%+)
  - Security scanning
- `.github/workflows/ci.yml.template` - Bash CI pipeline

### Documentation
- `tests/README.md` - Testing guide with examples

## Quality Standards

- **Linting**: ShellCheck (severity: warning+)
- **Formatting**: shfmt (4-space indent, bash dialect)
- **Testing**: Bats (Bash Automated Testing System)
- **Coverage**: kcov 70%+ line coverage
- **Security**: ShellCheck security rules

## Testing Libraries

Uses Bats with helper libraries:
- **bats-support**: Output formatters and test helpers
- **bats-assert**: Rich assertion functions
- **bats-file**: File/directory assertions

## Usage

```bash
# Copy templates to Bash project
cp build-tools/bash/.shellcheckrc myproject/
cp build-tools/bash/Makefile myproject/
cp -r build-tools/bash/tests myproject/

# Install Bats helpers
cd myproject/tests
./install-bats-helpers.sh

# Run tests
cd ..
make test

# Check coverage
make coverage
```

## Makefile Targets

- `make lint` - Run ShellCheck on all .sh/.bash files
- `make format` - Format with shfmt
- `make test` - Run Bats test suite
- `make coverage` - Generate kcov coverage report
- `make security` - Security scanning (ShellCheck + custom checks)
- `make all` - Run all checks
- `make watch` - Watch files and auto-test

## Version Format

FlossWare projects use **X.Y versioning** (not X.Y.Z):
- Examples: `0.1`, `1.0`, `1.1`, `2.0`
- Simpler version management
- Matches FlossWare build-tools standard (currently 2.0)

For Bash projects, version can be defined as:
```bash
# In main script
VERSION="1.0"  # Use X.Y format

# Or in Makefile
PROJECT_VERSION := 1.0
```
